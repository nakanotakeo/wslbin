# ProCAIreport.py マニュアル

`ProCAIreport.py` は、プログラミング C の提出物に含まれる AI 会話ログの HTML を調べ、学生側の発言回数と HTML への相対リンクを採点用 Excel の G 列（評価メモ）に記入するスクリプトです。

このマニュアルは、保存先 `AIhtml/`、MOTW の追加、Excel のハイパーリンク書式、表示文字列の簡略化を反映した、2026 年 10 月 10 日の修正版に対応しています。

## 1. 動作環境

- Python 3.9 以降。
- 外部パッケージのインストールは不要です。Python の標準ライブラリだけで動作します。
- 以下の実行例は WSL / Debian のコマンドラインを想定しています。

Python のバージョンは次のコマンドで確認できます。

```bash
python3 --version
```

HTML の解析時に JavaScript は実行せず、AI サービスなどへの通信も行いません。

## 2. 入力の準備

提出物の ZIP を通常どおり展開し、提出物フォルダと採点用 Excel が同じ親フォルダにある状態にします。スクリプトには **ZIP 自体ではなく、展開した親フォルダ**を指定します。

例えば `~/Dropbox/ProgrammingC/ProgC2c1_02/` に、次の項目がある状態です。

| 種類 | 名前の例 |
| --- | --- |
| 提出物フォルダ | `report_REP0000001317907_20261010131220/` |
| 採点用 Excel | `rptevaluation_REP0000001317907_20261010131747.xlsx` |
| 提出 HTML（提出物フォルダ内） | `S235023_us235023_02_日本語タイトル.html` |

入力には次の条件があります。

- 指定した親フォルダ直下に、`report_REP[_0-9]+` に一致するフォルダが **1 件**あること。複数の授業回は別々の親フォルダに分けて実行します。
- 採点表を自動選択する場合、親フォルダ直下に `rptevaluation_REP[_0-9]+.xlsx` に一致するファイルが **1 件**あること。複数ある場合は `--xlsx` で指定します。
- 採点表の G 列に「評価メモ」があるワークシートが **1 枚**あること。
- 採点表の A 列のユーザー ID（例：`us235023`）または H 列の学籍番号（例：`S235023`）から、学生の行を識別できること。
- HTML の名前が `S235023_us235023_02_タイトル.html` のように、学籍番号・ユーザー ID・2 桁の提出ファイル番号を持つこと。

提出物フォルダ内は、下位フォルダも含めて検索します。拡張子 `.html` と `.htm` が対象で、拡張子の大文字・小文字は区別しません。C ソース、テキスト、Word ファイルなどは対象外です。

## 3. 基本的な実行方法

`ProCAIreport.py` を `~/wslbin/` に保存した場合、次のように実行します。

```bash
python3 ~/wslbin/ProCAIreport.py ~/Dropbox/ProgrammingC/ProgC2c1_02
```

既に対象の親フォルダで作業している場合は、フォルダ指定を省略できます。

```bash
cd ~/Dropbox/ProgrammingC/ProgC2c1_02
python3 ~/wslbin/ProCAIreport.py
```

`ProCAIreport.py` を対象フォルダの 1 つ上に置いた場合は、対象フォルダ内から次のように実行できます。

```bash
python3 ../ProCAIreport.py
```

空白を含むパスは引用符で囲んでください。

```bash
python3 ~/wslbin/ProCAIreport.py "/mnt/c/Users/nakano/授業資料/Programming C"
```

## 4. 生成されるファイル

既定では、入力の採点表と同じ場所に次の項目を作成します。

| 出力 | 内容 |
| --- | --- |
| `rptevaluation_AIreport.xlsx` | AI 利用の記録とリンクを G 列に記入した採点表 |
| `AIhtml/` | 英数字名にした HTML のコピーを置くフォルダ |

HTML のコピー名は、元の名前に含まれる学籍番号・ユーザー ID・提出ファイル番号を維持し、後ろのタイトルを除いて作ります。番号を振り直す処理はしません。

| 元の名前 | コピー先（出力 Excel からの相対パス） |
| --- | --- |
| `S235023_us235023_02_日本語タイトル.html` | `AIhtml/S235023_us235023_02.html` |
| `S247075_us247075_01_会話ログ.html` | `AIhtml/S247075_us247075_01.html` |

コピー名は `S[0-9]{6}_us[0-9]{6}_[0-9]{2}.html` の形式です。元の名前で区切りの `_` が複数続いている場合も、コピー名では 1 つにまとめます。

**Excel 内のリンクは、元の提出 HTML ではなく、`AIhtml/` 内のコピーに向けます。** コピーには、以下の MOTW コメントを追加します。元の採点表と元の提出物は変更しません。

出力 Excel を移動・配布する際は、`AIhtml/` も一緒に移動し、Excel と同じフォルダに置いてください。

### HTML コピーへの MOTW の追加

Excel からローカル HTML を開いたときのアクティブ コンテンツ警告への対処として、コピーに次のコメントを付けます。

```html
<!-- saved from url=(0014)about:internet -->
```

これは Internet Explorer 系の仕組みに、その HTML をインターネット ゾーンとして扱うよう伝える **Mark of the Web（MOTW）** です。

- 先頭付近に既存の MOTW コメントがある場合は、このコメントに置き換えます。
- 既存の MOTW が見つからなければ、先頭付近の `<!DOCTYPE html>` の直後に追加します。DOCTYPE がない場合などは、ファイル先頭（BOM がある場合はその直後）に追加します。
- コメントの `-->` の直後には、実際の CRLF（`\r\n`）を付けます。文字列としての `\r\n` を HTML に書き込むわけではありません。
- HTML 本文の改行は一括変換しません。文字コードも維持します。UTF-8 の BOM、および BOM 付き UTF-16 LE / BE にも対応します。
- 質問回数は、コメント追加前の元の提出 HTML から数えます。

この処理はコピーだけに行います。元の提出 HTML は変更しません。再実行しても、追加した MOTW は重複しません。

**警告が消えるかは、Office のバージョンや PC の設定に依存します。** 実際に警告が出る PC で確認してください。Office 全体のハイパーリンク警告など、別の種類の警告を一律に無効にする機能ではありません。

参考：[Microsoft — Mark of the Web](https://learn.microsoft.com/en-us/previous-versions/windows/internet-explorer/ie-developer/compatibility/ms537628(v=vs.85))

## 5. G 列の記入内容と回数の定義

回数を判定できた場合は、次の形式で記入します。

```text
AI利用(質問3回)
```

判定できない場合は、次の形式で記入します。

```text
AI利用(質問回数不明)
```

リンクは G 列の該当セル全体に設定し、**青字・下線のハイパーリンク書式**にします。`[リンク]` という文字列は付けません。元のフォント名・サイズ、配置、罫線、背景色、表示形式は保持します。既存の評価メモがある場合は、そのメモも含めてセル全体がリンクになります。

リンク先は、Excel でセルを右クリックして［ハイパーリンクの編集］（または［リンクの編集］）を開き、［アドレス］で確認できます。セルに直接設定したリンクなので、数式バーに `HYPERLINK` 関数としては表示されません。相対リンクの例は `AIhtml/S235023_us235023_02.html` です。

ここでいう「質問回数」は、**HTML に記録されている学生側の送信回数**です。次のような送信も 1 回として数えます。

- コードや実行結果の送信。
- 相づちや訂正。
- AI からの質問に対する学生の回答。
- 会話を HTML にする依頼。

疑問符の数や AI の回答数は数えません。1 回の送信に複数の質問が含まれていても、1 回です。また、HTML に残っていない会話は推定しません。抜粋ログの場合は、その抜粋に記録された回数になります。

G 列に既存の評価メモがあれば、その後に改行して追記します。このスクリプトと同じ形式の `AI利用(...)` が既にある場合は、その部分を更新します。旧版の `AI利用(...) [リンク]` も認識し、`[リンク]` を省いた新しい表示に更新します。

G 列の幅は、少なくとも 36 に広げます。得点や他の列の内容は変更しません。既存の数式や、AI 利用記録以外のリンクが対象の G セルにある場合は、処理を停止します。

HTML がない学生の行には追記しません。既存の AI 利用記録がある行でも、今回 HTML がなければ自動削除はしません。

## 6. 複数の HTML がある学生

同じ学生の HTML が複数ある場合は、各ファイルの回数を合計し、次のように件数を付けます。

```text
AI利用(質問8回)（HTML 2件）
```

- 各 HTML はすべて `AIhtml/` にコピーします。
- Excel のセルに設定するリンクは 1 つで、元ファイルのパスをソートした先頭の HTML に向けます。
- 1 件でも回数不明の HTML があれば、合計も「質問回数不明」とします。
- 同じ会話が複数の HTML に含まれていても、自動では重複を除外しません。実行時に表示される注意を確認してください。

異なる元ファイルが同じコピー名になる場合は、取り違えを避けるためエラーにします。`--force` を付けても、この名前衝突は解消しません。

## 7. オプション一覧

| 引数・オプション | 内容 | 省略時 |
| --- | --- | --- |
| `directory` | ZIP を展開した親フォルダ | 現在の作業フォルダ |
| `--xlsx PATH` | 入力の採点表を指定 | 親フォルダ直下の該当ファイルを自動選択 |
| `-o PATH` / `--output PATH` | 出力 Excel のパスを指定 | 入力 Excel と同じ場所の `rptevaluation_AIreport.xlsx` |
| `--force` | 既存の出力 Excel と、今回対象の HTML コピーを更新 | 異なる内容の既存ファイルは上書きしない |
| `--counts PATH` | 手動補正用の JSON ファイルを指定 | HTML から自動判定 |
| `-h` / `--help` | 使い方を表示 | — |

`directory`、`--xlsx`、`--output`、`--counts` に渡す相対パスは、すべて **コマンドを実行している現在の作業フォルダ**を基準に解釈します。

### 再実行して出力を更新する

```bash
python3 ~/wslbin/ProCAIreport.py . --force
```

`--force` は元の入力 Excel を上書きする指定ではありません。入力と出力が同じパスなら、`--force` を付けてもエラーにします。

MOTW 追加後の内容と一致する HTML コピーはそのまま使い、内容が変わった対象のコピーは更新します。今回の対象になっていない古いコピーは、自動では削除しません。

### 旧版から更新する

旧版の `ProChtmlAI/` は自動で移動・削除しません。再実行すると、新しい `AIhtml/` にコピーを作り、出力 Excel のリンクを更新します。既存の Excel や HTML を更新する場合は `--force` を付けてください。採点済みの Excel を使う場合は、下の「生成済みの採点表に採点を書き込んだ後、AI 記録を更新する」の手順で採点内容を引き継ぎます。

### 入力の採点表を指定する

```bash
python3 ~/wslbin/ProCAIreport.py . \
  --xlsx rptevaluation_REP0000001317907_20261010131747.xlsx
```

### 出力先を指定する

```bash
python3 ~/wslbin/ProCAIreport.py . -o result/rptevaluation_AIreport.xlsx
```

この場合は `result/AIhtml/` に HTML をコピーし、`result/` 内の Excel から相対リンクを張ります。必要な出力フォルダは自動作成します。

### 生成済みの採点表に採点を書き込んだ後、AI 記録を更新する

生成済みの `rptevaluation_AIreport.xlsx` に得点などを追記した後で、元の空の採点表を入力として `--force` を実行すると、出力に書き込んだ採点内容は引き継がれません。

採点内容を引き継ぐには、採点済みの Excel を入力として明示し、別名に出力します。

```bash
python3 ~/wslbin/ProCAIreport.py . \
  --xlsx rptevaluation_AIreport.xlsx \
  -o rptevaluation_AIreport_v2.xlsx
```

## 8. 質問回数の手動補正

未知の形式や抜粋ログなどについて手動で回数を確認した場合は、UTF-8 の JSON ファイルを作り、`--counts` で指定できます。

例えば `counts.json` を次の内容で保存します。

```json
{
  "report_REP0000001317907_20261010131220/S235023_us235023_02_日本語タイトル.html": 3,
  "report_REP0000001317907_20261010131220/S247075_us247075_01_会話ログ.html": null
}
```

- キーは、`directory` で指定した親フォルダからの **元 HTML の相対パス**です。`AIhtml/` のコピー名ではありません。
- パスの区切りは `/` にします。
- 値は 0 以上の整数です。`null` を指定すると「質問回数不明」になります。
- 指定したファイルについては、自動判定より手動補正を優先します。
- JSON に指定していない HTML は、従来どおり自動判定します。
- 対象に存在しないパスを指定するとエラーになります。

実行例です。既に出力がある場合は `--force` も指定します。

```bash
python3 ~/wslbin/ProCAIreport.py . --counts counts.json --force
```

JSON に指定するパスは、実際のファイル名と一致させてください。上の名前は記入形式の例です。

## 9. 自動判定の対応形式と限界

HTML の発言者属性・タグ・クラス・見出しなどから、学生側の発言を識別します。現行版は、今回の提出物で確認した次の形式に対応しています。

| 形式 | 主な識別方法 |
| --- | --- |
| ChatGPT の保存ページ | 発言者属性、または「あなた」「あなたの発言」などの見出し |
| Gemini の保存ページ | `user-query` タグ |
| Claude の保存ページ | `data-testid="user-message"` |
| 整形済みの対話ログ | `user` などのクラス、発言者ラベル |
| `User prompt:` 付きログ | プロンプトのラベル |
| `PROMPT` バッジ付きログ | プロンプトを示すバッジ |

同じ発言に複数の識別方法が使われていても、方式を合算しません。同じ方式のマーカーが入れ子になっている場合も、外側の 1 件として数えます。

学生側の発言を識別できないときは、0 回とせず「質問回数不明」にします。主な原因は、会話本文が HTML に保存されていない、AI の回答だけが保存されている、保存形式が未対応である、といったものです。

サービス名が同じでも、画面や HTML の構造が変われば対応の修正が必要になる場合があります。実行時に表示される各ファイルの回数・判定方法・不明件数を確認してください。

コピーするのは HTML 本体だけです。別ファイルの画像・CSS などは収集しません。HTML が相対パスで外部ファイルを参照する場合、コピー先でその画像や装飾を表示できないことがあります。

## 10. エラー時の対処

| 表示・状況 | 確認すること |
| --- | --- |
| 出力が存在する | 更新する場合は `--force` を付ける。別名で残す場合は `-o` を使う。 |
| 採点表が 0 件・複数件ある | 親フォルダの指定を確認する。複数ある場合は `--xlsx` を使う。 |
| `report_REP...` フォルダがない | ZIP を展開した親フォルダを指定する。提出物フォルダ自体ではなく、その 1 つ上を指定する。 |
| `report_REP...` フォルダが複数ある | 授業回ごとに親フォルダを分けて実行する。 |
| 採点表と提出物の REP 番号が異なる | 同じ課題の採点表と提出物を組み合わせる。 |
| G 列の「評価メモ」が一意に見つからない | 採点表の列構成・見出し・シート数を確認する。 |
| 採点表に対応行がない、ID が重複している | HTML の名前と採点表の A 列・H 列を確認する。 |
| HTML のコピー名を作れない | `Sxxxxxx_usxxxxxx_XX_...` の形式になっているか確認する。 |
| HTML のコピー名が重複する | 同じ識別用接頭辞を持つ別ファイルがないか確認する。 |
| 異なる内容の HTML コピーが存在する | 更新してよい場合は `--force` を付ける。 |
| G セルに既存の数式・別用途のリンクがある | 対象セルを手動で確認する。スクリプトはその内容を自動で上書きしない。 |
| HTML がない | HTML が提出物フォルダ内にあるか確認する。HTML が 1 件もなければ出力は作成しない。 |
| Excel を保存・置換できない | 出力 Excel を開いている場合は閉じ、書き込み権限と出力先を確認する。 |
| Excel から HTML を開くと警告が出る | 最新版でコピーを再生成し、コピーに MOTW があるか確認する。警告の有無は PC の設定などにも依存する。 |
| Excel のリンク先が見つからない | 出力 Excel と `AIhtml/` が同じ場所にあるか、対象 HTML が存在するか確認する。 |

正常終了時の終了コードは `0`、処理エラー時は `1` です。入力チェックに失敗した場合は、新しい採点表を保存しません。HTML コピーの保存途中で失敗した場合は、コピーの一部だけが残ることがあります。
