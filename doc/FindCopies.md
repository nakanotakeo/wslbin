# FindCopies.py

## 目的

二つのディレクトリの `build/` 直下にある `*.c` を一つのプールにまとめ、**ファイルのバイト列が完全に一致するグループ**を表示します。同じディレクトリ内の一致も、ディレクトリをまたぐ一致も検出します。

`FindDuplicates.py` のようなトークン化や正規化は一切行いません。空白・改行・コメント・文字コード・BOM・末尾改行の有無のいずれかが違えば、不一致です。

一致はファイルの完全一致を示すもので、コピーした事実そのものを証明するわけではありません。

## 必要なもの

Python 3.8 以降。Python 標準ライブラリのみを使用します。`FindCopies.py` 単独で動作し、`ProCtokens.py` や `FindDuplicates.py` は不要です。

## 使い方

```bash
python3 FindCopies.py dirA dirB
```

引数は `build/` 自体ではなく、その親ディレクトリです。パスに空白がある場合は引用符で囲みます。

```bash
python3 FindCopies.py "class A" "class B"
```

Windows では環境に応じて `python3` を `py -3` に置き換えてください。

## 対象ファイル

- `dirA/build/*.c` と `dirB/build/*.c` の直下のみ。再帰検索は行いません。
- 拡張子は小文字の `.c` のみ。`.C`、`.cpp` などは対象外です。
- ファイル名は一致条件に含めません。名前が違っていても内容が同じなら同じグループです。
- `.c` ファイルへのシンボリックリンクはリンク先の内容を読み込みます。
- 同じ `build/` を指す二つの引数はエラーにします。
- **空ファイルやコメントだけのファイルも含めて、そのまま比較します。** 0バイトのファイルが複数あれば、それらも一致グループになります。
- C としての適法性は検査しません。文字コードの解読も行わないので、文字コード指定のオプションはありません。

## 出力例

```text
一致 3:
   1: dirA/build/foo.c
   2: dirA/build/bar.c
   3: dirB/build/bar.c

比較対象: 計 20 ファイル（A 10 / B 10）
一致: 1 グループ / 3 ファイル
```

`一致 3:` の数字はグループ内のファイル数です。グループの通し番号ではありません。2ファイル以上のグループだけを表示します。一致がなければ、集計に `一致: 0 グループ / 0 ファイル` と表示します。

A 側のファイル名順、次に B 側のファイル名順に読み込みます。グループ内の表示はこの読込み順で、グループの順序は最初のメンバーが現れる順です。タブ・改行を含む特殊なパスだけは JSON の引用表記で表示します。

## 保存

通常の表示をテキストに保存する例です。

```bash
python3 FindCopies.py dirA dirB > copies.txt
```

集計と一致グループは標準出力、警告・個別エラーは標準エラー出力です。すべてを一つに保存するなら、次のようにします。

```bash
python3 FindCopies.py dirA dirB > copies.txt 2>&1
```

### TSV 形式

```bash
python3 FindCopies.py --tsv dirA dirB > copies.tsv
```

1ファイル1行で、次の4列を出力します。先頭行は列名です。一致がなければ列名だけになります。`--tsv` の場合、集計も標準エラー出力に出します。

| 列 | 内容 |
| --- | --- |
| `group_id` | グループの通し番号（1から） |
| `group_size` | グループ内のファイル数 |
| `member_index` | グループ内のメンバー番号（1から） |
| `file` | ファイルパス |

同じ `group_id` の行が同じグループです。タブ・改行・引用符を含むパスは CSV と同じ引用規則で保護します。特殊なファイル名を含む TSV は、Python の `csv.reader(..., delimiter='\t')` などで読み込んでください。

## 比較方法

各ファイルをバイナリで一度読み込み、SHA-256 とバイト列そのものの両方をグループ化のキーにします。ハッシュだけで一致を判断しません。入力ソースの変更、コンパイル、実行、中間ファイルの作成は行いません。読み込んだデータはメモリに保持します。

| ファイル間の違い | 判定 |
| --- | --- |
| ファイル名だけが違う | 一致 |
| スペースが一つ増えた | 不一致 |
| 改行が一つ増えた | 不一致 |
| CRLF と LF | 不一致 |
| UTF-8 BOM の有無 | 不一致 |
| UTF-8 と CP932 | 実際のバイト列が違えば不一致 |
| コメントの内容だけが違う | 不一致 |
| 最終行末の改行の有無 | 不一致 |
| 両方とも0バイト | 一致 |

## エラーと終了ステータス

個別ファイルの読込み失敗は明示し、そのファイルを除外して残りの比較を続けます。結果は読込み成功分だけである旨を集計に表示します。

`build/` が存在するが `.c` がない場合は、注意を表示して0ファイルとして処理します。

| 終了ステータス | 意味 |
| --- | --- |
| `0` | 比較完了。一致の有無には依存しない |
| `1` | 個別ファイルに読込み失敗あり。結果は成功分のみ |
| `2` | 引数、比較ディレクトリの指定・列挙などのエラー |

ヘルプは次で表示できます。

```bash
python3 FindCopies.py --help
```
